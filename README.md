# Football AI Agenda

Agenda de fútbol con probabilidades, valor esperado y constructor de parlay.

Página original inspirada en 365Scores y OneFootball, con datos de ejemplo listos para football-data.org o API-Football.

## Uso

Abre `index.html` en el navegador para ver la agenda.

## Datos

Los datos incluidos son de ejemplo. Para datos en vivo, conecta football-data.org o API-Football.
